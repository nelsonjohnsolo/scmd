# SCMD — Stop Calling Me Daddy

Claude Code quietly saves notes about you while you work. SCMD shows you every one, as a card. Swipe left on the weird ones.

```
npx -y @nelsonjohnsolo/scmd
```

**This is a placeholder release to reserve the name.** v0.1.0 — the actual tool — is in progress.

- Zero dependencies. One command. Nothing leaves your machine.
- Keep or delete with a swipe or a keystroke. Nothing is written until you confirm.
- "Why was this saved?" shows the moment in the session that produced a memory.
- Rewrite a memory in plain language using your own local Claude Code.
